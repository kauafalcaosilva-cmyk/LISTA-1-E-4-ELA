# Atividade 1 - Elevador

Disciplina: Linguagens de Programação I
Professor: Wellynton José Diniz de Sousa

## Objetivo
Coletar informações sobre o elevador e o período mais utilizado pelos moradores, identificando:
- elevador mais utilizado;
- período mais utilizado;
- diferença percentual entre o período mais usado e o menos usado.

## Execução
No VS Code, abra este arquivo e execute:

```bash
python atividade_1_elevador.py
```
